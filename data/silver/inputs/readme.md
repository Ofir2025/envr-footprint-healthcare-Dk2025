# Silver country inputs

This directory contains validated, model-ready country inputs derived from
immutable Bronze sources.

- `dk_data_2025.csv` is regenerated from
  `data/bronze/dst_supply_use/dk_umat_2019.xlsx` by the
  Denmark analysis and is written in MEUR with `Conversion=1.0`.
- `dk_bottomup_data_2025.txt` is generated by scaling the Dutch bottom-up
  baseline to Denmark.
- `dk_atc_sales_<year>.csv` is the Danish Medicines Agency register with named
  columns, written by `analysis.build_atc_sales` from the headerless
  semicolon-separated originals in `data/bronze/dk_medicines_register/`. The raw
  files stay in bronze unchanged; this is where they become readable. 1.8 M rows
  and ~78 MB per year, so it is not in version control - rebuild it by running
  the module.

`dk_data_2025.csv` and `dk_bottomup_data_2025.txt` carry an `ISO2` column (`DK`)
so country ownership is explicit. The source files remain in Bronze and are not
overwritten by the pipeline.
