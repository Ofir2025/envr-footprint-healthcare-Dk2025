# Silver country inputs

This directory contains validated, model-ready country inputs derived from
immutable Bronze sources.

- `dk_data_2025.csv` is regenerated from `data/bronze/dk_umat_2019.xlsx` by the
  Denmark analysis and is written in MEUR with `Conversion=1.0`.
- `dk_bottomup_data_2025.txt` is generated by scaling the Dutch bottom-up
  baseline to Denmark.

Both files carry an `ISO2` column (`DK`) so country ownership is explicit.
The source files remain in Bronze and are not overwritten by the pipeline.
