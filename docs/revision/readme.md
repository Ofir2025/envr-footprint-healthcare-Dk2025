# Revision

The working record of the manuscript revision: the analysis behind the
headline results, every open question and defect found along the way, the
formal correspondence with reviewers, and the material a co-author needs to
check a claim. This folder is large because it is the revision's own paper
trail; `docs/readme.md` links the pieces a first-time reader needs most.
